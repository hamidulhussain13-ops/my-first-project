# 📈 Stock Price Prediction App

This project is a Streamlit-based web application that predicts stock price movement using a Machine Learning model (Decision Tree Classifier).

## 🚀 Features
- Predict stock price direction (Up/Down)
- Interactive UI using Streamlit
- Uses synthetic financial dataset
- ML model: Decision Tree Classifier

## 🛠️ Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
